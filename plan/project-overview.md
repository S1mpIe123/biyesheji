# Project Overview

## 论文基本信息

- **题目**：基于 Spring Boot 和 Vue 的农产品产销对接平台设计与实现
- **类型**：本科毕业设计（论文）
- **学科**：计算机科学与技术 / 软件工程
- **语言**：中文

## 项目定位

本项目不是单纯的农产品商城，而是在商城功能基础上扩展了供应发布、采购需求、智能匹配、供需撮合、订单闭环、后台审核和数据分析等业务。论文写作应突出"产销对接"主线。

## 技术栈

- **后端**：Spring Boot 3.3.1 + MyBatis + PageHelper + MySQL
- **前端**：Vue 3 + Vite + Element Plus + Axios + Vue Router
- **架构**：B/S 前后端分离

## 用户角色

1. 管理员 (ADMIN) — 审核、数据分析、用户管理
2. 供应商 (SUPPLIER) — 发布供应、查看推荐、发货
3. 采购商 (BUYER) — 发布采购需求、查看推荐、发起意向
4. 普通购买用户 (SHOPPER) — 浏览商品、下单、查看订单

## 核心业务模块

- 基础模块：用户管理、分类管理、商品管理、库存管理、公告管理、订单管理、文件管理
- 产销对接模块：供应发布、采购需求、智能匹配推荐、撮合记录、审核、数据分析、消息中心

## 已知约束

- 权限控制为菜单级 + 后端业务校验，非完整 Spring Security/JWT 体系
- 智能匹配为规则权重算法，非机器学习
- 前端 AI 分析为本地规则模拟，不依赖外部大模型
- 写作避免第一人称、口语化、明显 AI 痕迹
